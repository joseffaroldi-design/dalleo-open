# Real Content Entry Checklist

Enter through the admin dashboard (/admin). Nothing here is fictional — every
item needs owner-approved real information before launch.

## Site Content (Admin → Site Content)
- [ ] Tournament edition (e.g., the official name of this year's event)
- [ ] Tournament year
- [ ] Confirmed date text for the hero
- [ ] Hero subtitle
- [ ] Instagram URL (real account)
- [ ] Homepage memorial message (family-approved)
- [ ] Memorial hero title and subtitle (family-approved)
- [ ] Memorial story paragraphs (family-approved)
- [ ] Memorial timeline milestones — real years/details if desired
- [ ] Closing message
- [ ] Memorial publication state
- [ ] Share a Memory section visibility

## Teams (Admin → Teams)
- [ ] Team names (real)
- [ ] Team color labels
- [ ] Captains
- [ ] Full rosters, one player per line (first line = Captain)
- [ ] Team mottos
- [ ] Published state on when rosters are final

## Leaderboard (Admin → Leaderboard)
- [ ] Confirmed round names
- [ ] Scoring-started toggle off until play begins
- [ ] Initial scores (or blank until play begins)
- [ ] Team statuses (Upcoming before play)
- [ ] Habit: update the "Last updated" text with each score change

## Schedule (Admin → Schedule)
- [ ] Confirmed events for Friday, Saturday, Sunday
- [ ] Real times (format "5:00 PM")
- [ ] Real locations
- [ ] Descriptions
- [ ] Event statuses kept current during the weekend
- [ ] One current event marked during play
- [ ] Published state on when confirmed

## Gallery (Admin → Gallery)
- [ ] Approved image URLs (hosted photos)
- [ ] Captions and descriptions
- [ ] Years
- [ ] Categories
- [ ] Alternative text for every image
- [ ] Featured memory selection
- [ ] Display order
- [ ] Published states

## Rules (Admin → Rules)
- [ ] Approved format description
- [ ] Final scoring values
- [ ] Match-rule answers
- [ ] Conduct language
- [ ] Tie-breaker order
- [ ] FAQs
- [ ] "Approved by organizers" switched on after sign-off
- [ ] Published state on

## Announcements (Admin → Announcements)
- [ ] Initial welcome announcement (published)
- [ ] Draft-results announcement ready for Friday night
- [ ] Plan for tournament-day updates (who posts, how often)
